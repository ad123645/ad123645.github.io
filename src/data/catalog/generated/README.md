# 中图分类数据（生成目录）

这组文件是为了博客馆藏系统生成的中图分类树数据。

## 这次整理的规模

- 总类号数：45785
- 叶子类目数：37105
- 含范围符号 `/` 的类号：151
- 方括号交替类号：1110
- 花括号停用类号：260

## 结构说明

- 每个一级大类一个目录，例如 `a/`、`b/`、`t/`
- 每个目录下按该大类的直属二级分支拆成多个 `.ts` 文件
- `index.ts` 负责把分段记录拼成该大类的完整树
- `stats.ts` 提供整套目录树的规模统计
- `src/data/catalog/clc.ts` 负责把全部一级大类装配成全站目录

## 记录格式

- `code` 类号
- `name` 类名
- `parentCode` 上位类号
- `childCodes` 官方顺序下的直接下位类号列表

## 标记保留策略

- 保留原始类号中的 `[]` 与 `{}`，避免把交替类号与停用类号抹平
- 运行时会额外推断 `marker` 字段：`normal | alternate | deprecated`
- 带 `/` 的范围类号会额外标记 `isRange: true`

这些文件由结构化中图分类数据与本地《中图分类法（第五版）》整理生成，目标是给博客目录页、文章挂架、路径导航和后续校验脚本提供完整树结构。
